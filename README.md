# Amazon Reviews Recommender

An end-to-end recommendation system built around Amazon Reviews 2023. The
project explores scalable interaction data preparation, recommendation
baselines, collaborative filtering, and a PyTorch two-tower model.

## Current work

- PySpark data preparation with validation, filtering, and time-based splits
- Popularity recommendation baseline
- PyTorch two-tower model with negative sampling
- Unit tests for data preparation and model components

The repository is under active development. See [PLAN.md](PLAN.md) for the
planned evaluation, serving, monitoring, resilience, security, and deployment
milestones.
